# Смерть в Космосе — лист персонажа

Мобильное приложение (React Native, без Expo) для настольной ролевой игры
**«Смерть в Космосе»** / *DEATH IN SPACE* (Free League Publishing, авторы
Кристиан Плогфорс и Карл Ниблеус).

Приложение — это официальный **«Лист персональных данных»**, перенесённый в
экран и полностью управляемый с телефона. Все данные хранятся локально в
**MMKV** (`react-native-mmkv` + `react-native-nitro-modules`), без сервера и
без аккаунтов.

## Возможности

- **Список персонажей** — своя карточка на каждого: хиты, защита, гало,
  очки пустоты, заполненность слотов. Долгое нажатие — удаление.
- **Мастер создания** — шесть шагов по книге правил:
  1. Способности — бросок 2d4, первая минус вторая (диапазон −3…+3).
  2. Происхождение — 6 вариантов, выбор одной выгоды из двух.
  3. Детали — имя, прозвище, фонд, черта, цель, внешность (все с бросками d20).
  4. Прошлое подчинение — d6.
  5. Хиты и защита — 1d8 на максимум хитов, защита 12+ЛОВ.
  6. Снаряжение и бонус — стартовый набор (d6), белка (d20), 3d10 гало,
     стартовый бонус (если сумма способностей отрицательна).
- **Лист персонажа** — все разделы официального бланка:
  - Раздел 0: информация игрока.
  - Раздел 1: личная информация, четыре способности (ТЕЛ / ЛОВ / РАЗУМ / ТЕХ),
    XP, происхождение и выгоды, защита и хиты.
  - Раздел 2: текущая ситуация — очки пустоты (максимум 4), мутации,
    жизнеобеспечение (7 шагов), порча пустоты.
  - Раздел 3: личное имущество — предметы с состоянием 1–5, мелкие предметы,
    два оружия (урон / заряды / состояние), броня с бонусом к защите, гало и долг.
  - Раздел 4: заметки.
- **Броски** — 1d20 + способность, преимущество и помеха (бросок дважды),
  выбор цели (12 для проверки или защита цели), дополнительные кубики,
  история бросков.
- **Справочник** — все игровые таблицы: происхождения, фонд, черты, цели,
  внешность, подчинение, наборы, белки, стартовые бонусы, 20 космических
  мутаций, 20 видов порчи пустоты, формулы и правила.

## Запуск

Требуется Node.js ≥ 22.11, Xcode (для iOS) или Android Studio.

```sh
npm install

# iOS: подтянуть нативные зависимости (MMKV/Nitro) один раз
cd ios && pod install && cd ..

npm start          # Metro
npm run ios        # или npm run android
```

## Проверки

```sh
npm run typecheck  # tsc --noEmit
npm run lint       # eslint
npm test           # jest
```

## Структура

```
App.tsx                     точка входа
src/
  components/               UI-примитивы (карточки, поля, степперы, треки)
  data/                     игровые данные: origins, tables, mutations, armor
  navigation/               навигатор и типы маршрутов
  screens/                  Roster, Create, Character, Roll, Tables
  store/
    storage.ts              экземпляр MMKV
    characterStore.ts       zustand + persist поверх MMKV
  utils/dice.ts             броски, 2d4, преимущество/помеха
  types.ts                  модель персонажа и производные значения
  theme.ts                  цвета, отступы, шрифты
__mocks__/react-native-mmkv.ts   мок MMKV для Jest
```

## Источник данных

Структура листа и все таблицы взяты из официального бланка персонажа и
«Книги правил» DEATH IN SPACE (Free League Publishing). Броня описана по
известным значениям бонуса к защите; конкретные предметы и оружие вносятся
игроком вручную, состояние считается по правилам книги (оружие и электроника
1–5).

Приложение — фанатское и не связано с Free League Publishing.
